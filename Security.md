# Security Policy

## Project Scope:
CloudGuard is an educational CSPM dashboard prototype. It currently displays simulated security findings and does not scan real cloud environments.

## Reporting a Problem:
 1. If you discover a defect in this demonstration, document the steps to reproduce it and include screenshots where appropriate.
 2. Do not submit cloud credentials, API keys, personal data, or other sensitive information in bug reports.

## Safe Use:
- Use only the supplied demonstration data unless you have an authorized, appropriate test environment.
- Do not treat the sample findings as evidence of real vulnerabilities.
- Do not use this prototype as a substitute for a production security monitoring solution.
